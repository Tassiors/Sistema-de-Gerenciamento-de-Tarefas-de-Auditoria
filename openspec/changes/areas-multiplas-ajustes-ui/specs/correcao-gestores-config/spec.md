# Capability: Correção de Gestores e Unidade Principal em Configurações

## Requirements
1. **Funcionamento dos Botões:**
   - O botão 'Cadastrar Novo Gestor' deve abrir o modal de inclusão com formulário limpo.
   - O botão 'Editar Matriz' deve abrir o modal populado com os dados do gestor selecionado.
2. **Campo Unidade Principal Obrigatório:**
   - O formulário deve apresentar com destaque o seletor de 'Unidade Principal' (dentre as 79 unidades do organograma).
   - A seleção da unidade principal deve desencadear a previsão da árvore subordinada herdada.
